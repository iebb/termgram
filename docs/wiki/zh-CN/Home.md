# Termgram 使用指南

[English](../en/Home.md) · [选择语言](../Home.md)

Termgram 使用 Telegram 的 MTProto 用户 API，访问已有私聊和群组。最多支持八个账号槽位，
同一时间连接一个账号。重新连接时，可以先阅读本地缓存。

文档描述的是其来源版本；用 `tg --version` 查看已安装版本。程序里的 `?` 帮助会显示
实际生效的 Lua 绑定。文档提供英文和简体中文；当前界面使用英文，输入框占位提示可自定义。

当前范围不包含广播频道、秘密聊天、通话、故事、GIF 选择器、全服务器消息搜索、
联系人管理、新建群组和群管理。也未实现话题导航、云草稿、多个账号同时在线、持久发送队列、
相册、定时/静默发送及 typing 状态。
已支持编辑、删除、复制、转发、[贴纸](Stickers.md) 和 Saved Messages，见[日常操作](UX.md)。
文件夹在官方客户端创建与编辑。
支持的链接和机器人按钮见[日常操作](UX.md)。
