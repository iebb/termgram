# 快捷键

[English](../en/Keybindings.md) · [指南首页](Home.md)

下表是默认值，`?` 显示当前 Lua 配置实际生效的绑定和可用命令。
按 `/` 或 Ctrl-F 搜索按键、说明、上下文和命令，输入时即时筛选并高亮匹配文字。
搜索按字面匹配，不区分大小写；Enter 保留筛选并恢复滚动，Esc 先清空搜索，再按一次关闭帮助。
浏览按键属于 `help` 上下文，编辑搜索词的按键属于 `input` 上下文。

大写字母表示 Shift 加该字母。
`g g`、`g i`、`g n`、`g p` 是依次按下；未完成的组合键一秒后过期，Esc 可取消。
按键作用于焦点面板或浮层，输入框里的普通字母仍然是文字。

`20k` 这类数字前缀在两个导航面板中生效。如果希望一个快捷键直接跳 N 条，
在 [Lua 配置](Configuration.md) 中设置 `count`。
`gg` 只到当前已加载历史的顶部，不会下载整个群从建立以来的全部消息；
阅读旧历史时，`G` 会重新加载最新页。

旧版默认值迁移：会话中的 `/` 现在打开本地搜索，机器人 `/命令` 请先按 `i` 再输入。
大写 `O` 定位文件，可操作项切换改为 `g n` / `g p`，`o` 展开图片预览。
`i` 也可从聊天列表进入输入；会话中明确选中消息时则回复该消息。账号选择使用方向键和 Enter；
导航中的数字用作数量前缀，已去掉旧的账号数字直达提示。
Lua 解析之后不再有另一套硬编码按键兜底。

点击回复引用区跳到原消息。选中回复时 Enter 默认跳转该目标，`g n` / `g p`
切换其他操作。点击媒体会选中附件，此时 Enter 激活附件操作。

导航模式按 `:` 打开[冒号命令](Commands.md)。Tab/Shift-Tab 或 Ctrl-N/Ctrl-P
补全前后候选；Up/Down 召回匹配前缀的历史；Enter 执行；Esc/Ctrl-C 取消。

输入框 Ctrl-O 打开附件列表，其中 a/p/d/o/O/i 分别添加、切换照片或文件、移除、预览、定位和编辑说明，见[附件](Attachments.md)。输入框 Ctrl-T 打开[贴纸面板](Stickers.md)，可选最近使用、收藏和已安装贴纸包。

会话、输入框和附件列表中的 Cmd-V / Ctrl-V / Alt-V / Ctrl-Alt-V 粘贴原生剪贴板的文件、图片或文字；也可用 `:paste`，不会自动发送。
