# 贴纸面板

[English](../en/Stickers.md) · [指南首页](Home.md)

在输入框按 Ctrl-T 打开贴纸面板。面板列出最近使用、收藏的贴纸以及所有已安装的
贴纸包，以 Telegram 原生贴纸方式发送所选贴纸——无需重新上传，草稿文字保持不变。

| 贴纸面板按键 | 行为 |
| --- | --- |
| hjkl 或方向键 | 在贴纸网格中移动 |
| PageUp/PageDown、Home/End | 在贴纸间移动 |
| Tab / Shift-Tab | 下一个 / 上一个分区 |
| 鼠标点击 | 选择分区或贴纸；再次点击已选中的贴纸即发送 |
| Enter 或 Space | 发送所选贴纸 |
| Ctrl-R | 重新获取最近使用、收藏和贴纸包列表；重试失败的贴纸包 |
| Esc 或 q | 关闭并返回输入框 |

左侧边栏列出分区：最近使用、收藏，以及每个已安装贴纸包一行。贴纸包内容在
第一次进入该分区时才加载，并在本次会话内缓存；最近使用、收藏和贴纸包列表
每次打开面板都会重新获取，因为 Telegram 的文件引用会过期。

网格单元格使用与消息预览相同的内联图片管线渲染贴纸的静态缩略图；缩略图
尚未下载完成的单元格显示该贴纸的 emoji。动态 TGS/WebM 贴纸按其静态缩略图
显示，这是预期行为。列表加载时面板显示加载提示；获取失败会显示错误，按
Ctrl-R 重试；空分区会有提示。缩略图按需下载，最多四个并行传输，并按文档
在媒体缓存中复用。

发送遵循当前回复状态：贴纸附带回复目标并清除回复状态，与发送草稿一致，
但草稿文字会保留。乐观的待发送消息会立即出现，Telegram 确认后替换；发送
失败只标记该消息。发送限制和慢速模式与文字消息同样生效。

入口动作是 `compose` 上下文中的 `stickers`（默认 Ctrl-T）。面板按键使用
`stickers` 上下文，动作包括 `open`、`cancel`、`refresh`、`up`、`down`、
`left`、`right`、`page_up`、`page_down`、`home`、`end`、`sticker_set_next`
和 `sticker_set_previous`。
