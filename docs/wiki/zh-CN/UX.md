# 日常操作

[English](../en/UX.md) · [指南首页](Home.md)

## 阅读和导航

宽窗口并排显示紧凑聊天列表和会话，输入框在会话下方对齐。F4 切换侧栏；
窄窗口一次显示一个面板，F4 或返回 Chats 显示列表并保留草稿。焦点边框与选择标记表明按键
将作用于哪里。Tab 切换焦点，Esc 先清除明确的消息选择，再从会话返回列表。
`j/k` 选择消息，方向键按实际显示行滚动，`G` 回到最新页。
阅读较早消息时，新消息保留当前阅读位置并显示计数，不会强行把视图拉到底部。

有未读消息的聊天会从保存的入站已读边界开始。紧凑的 `Unread messages` 分界会留在
进入时的位置，不会随着回执移动。先显示本地页面，Telegram 确认位置后才开始自动回执。
按 `g u` 或 `:unread` 可再次定位到当前首条未读。读到一页末尾时继续按 `j`、Down 或
PageDown，会加载后续历史，不会跳过中间消息。还有后续页时，底栏显示 `continue` 和
`latest` 提示；`G` 明确回到最新页。位置请求失败时保留缓存，可用 `g u` 重试，或用 `G`
离开该位置。

`g r` / `:read` 将目标聊天全部标读；`g U` / `:mark-unread` 设置 Telegram 的未读提醒。
没有实际未读消息时，提醒显示为彩色圆点，不会倒退已发送给其他人的回执。重新打开并
显示聊天会清除提醒，普通自动回执仍只确认实际可见的消息。打开命令栏后即使列表重排，
命令仍作用于原先选中的聊天。

列表里的 `[`/`]` 切换[文件夹](Folders.md)，`/` 过滤当前文件夹的标题。
[预设聊天别名](Configuration.md) 按稳定的 Telegram ID 从 All chats 打开目标；
`g i` 显示聊天和文件夹 ID，便于配置。

先显示缓存，连接状态与加载提示说明后台同步进度。本地搜索和本地偏好可以离线使用；
发送以及服务器操作需要完成认证并联网。待执行命令队列有上限，发送失败会保留可重试消息。


底栏显示键盘模式、账号和连接信息。选择消息会改变上下文提示；INSERT 表示正在输入。
可以在 [Lua](Configuration.md) 中配置可选 Ping/DC 诊断与阅读位置。
长错误在底栏上方展开，保留具体原因和当前模式。

作者、回复引用、正文和媒体分行显示。当前消息与当前操作有各自的可见标记；
完整作者名自动折行；消息默认不留空白分隔行，以交替底色区分。时间、可选 ID、
送达和媒体状态集中在底栏。

## 阅读带格式的消息

支持 Telegram 粗体、斜体、下划线和删除线，以及嵌套样式和 Unicode 表情。
行内代码高亮；代码块保留缩进和行尾空格，并在提供时显示语言。引用使用缩进竖线。
代码和正文按终端可用宽度换行。自定义表情保留 Telegram 提供的 Unicode 回退文字，
终端不播放其动画。普通消息里的 Markdown 符号保持原样。

剧透默认以遮罩显示。点击对应消息行，或用 `g n` / `g p` 选中剧透操作后按 Enter，
可以揭示或再次隐藏；`:spoiler` 对选中消息执行同样操作。Telegram 可折叠引用默认
最多显示三行，点击引用或在对应操作上按 Enter 可展开/收起，也可使用 `:quote`。
底栏显示当前可用操作。回复原消息的跳转仍保留独立操作和点击区域。

揭示状态仅属于当前账号和进程；正文或格式变化后重新隐藏。回复摘要、聊天预览、
搜索结果、置顶摘要、转发/删除预览以及通知始终遮住剧透。有剧透的消息在揭示前
不显示其链接操作行，包括隐藏链接的真实目标。显式复制和编辑仍使用完整原文。
格式随消息缓存；旧缓存会在重新获取该消息时补齐。当前读取服务端提供的格式，
输入框暂不提供创建格式的操作。Lua 可在 `conversation` 上下文绑定 `spoilers`
和 `expand_quote`。

## 输入和回复

点击输入框或按 `i` 输入。聊天列表中的 `i` 会继续当前会话；没有打开的会话时，恢复
当前 Telegram 账号上次打开的聊天，重启后也有效。目标不可用时选择列表中高亮的聊天，
空列表会提示等待同步。空白输入框显示可配置的 ghost text，不再常驻另一行重复发送按键。
Enter 发送，Shift-Enter 或 Ctrl-J 换行，机器人命令也在这里输入，包括开头的 `/`。
在草稿开头输入 `/`，或在空白后输入 `@`，会弹出候选框列出聊天的机器人命令和成员；
Tab 与方向键循环候选，Enter 接受高亮项，Esc 关闭弹窗。
Ctrl-T 打开[贴纸面板](Stickers.md)，可选最近使用、收藏和已安装贴纸包；
发送贴纸保留草稿文字并遵循当前回复。
每个聊天保留独立的本地草稿，包含正文、回复对象和光标位置。Esc、切换账号和正常重启都会
保留草稿。草稿使用 Telegram 用户身份隔离；复用本地账号槽位不会显示另一个账号的草稿。
后台以 400 毫秒窗口合并编辑，正常退出时写完最后一批。强制终止或断电可能丢失尚未提交的编辑。
本版本的草稿仅保存在这台设备，尚不包含云草稿同步。

选中消息按 `i` 或 `R` 回复；未选择时 `R` 回复最新消息。输入框显示回复目标。
点击输入框会保留已有回复草稿，不会因为消息选择而新建回复。
第一次 Esc 取消回复关系并保留文字，第二次 Esc 返回导航。`r` 跳到消息引用的目标。
发送失败会保留文字和回复目标；激活失败的发出消息，可回到输入框重试。

回复引用显示原作者和最多两行摘要，点击引用区或选中回复后按 Enter 跳到原消息；
`r` 也可直接跳转。先查内存和本地缓存，同屏缺失目标再合并为有界后台请求。
尚在加载与原消息不可用会在底栏区分，编辑/删除不会被晚返回的旧摘要覆盖。

## 编辑消息或说明文字

选中已送达消息，按 `e` 或输入 `:edit`。应用先获取服务器最新原文，检查作者、媒体类型
及 Telegram 配置中的编辑时限。转发、机器人代发或不支持的消息会在底栏说明原因；
聊天权限最终以服务器返回为准。

编辑框显示聊天与消息编号，底栏显示 EDIT 和当前快捷键。Enter 保存，Shift-Enter 或
Ctrl-J 换行。Esc/Ctrl-C 关闭并保留编辑；选中该消息按 `e` 或 `:edit` 继续这份编辑，
选中其他消息按 `e` 则编辑所选消息——未改动的保留编辑会被替换，已修改的会保留并提示。
编辑框中 Ctrl-D，或 `:edit-discard`，丢弃这份本地编辑。每个聊天保存一份编辑，
与普通草稿、回复对象和附件分开；采用本地草稿的保存机制，正常重启或切换账号后保留。

保存失败保留输入；服务器原文已经变化时提示冲突，不用服务器内容覆盖你的修改。
要从最新原文重新开始，可丢弃本地编辑后重新打开。Telegram 没有原子“比较版本再编辑”
接口，因此校验与提交之间的短暂时间内仍可能与其他客户端竞争。允许清空媒体说明，
纯文字消息不能保存为空；此编辑器不更换媒体本身。

修改范围前后的格式按 UTF-16 偏移保留；覆盖整个修改范围的样式相应调整长度。
部分被修改的实体，以及内容改变的隐藏链接/自定义表情目标，会被移除，避免错误关联。
一次编辑多个分散位置时，首末修改之间的格式也可能被移除。编辑更新走现有有序同步流，
并更新缓存和回复预览；选中消息的编辑时间显示在底栏。

## 文件、链接和鼠标

用 `:attach <路径...>` 将文件加入聊天草稿。默认粘贴路径保留为文字。
输入框 Ctrl-O 打开附件列表，可选发送格式、预览和移除；回到输入框按 Enter 发送，
第一份文件携带当前文字和回复目标。详见[附件](Attachments.md)。

点击媒体选择后，`o` 打开大图、`i` 回复。用 `g n` / `g p` 选择可操作项，Enter 激活。Telegram URL 实体会显示为可选择的链接行，
包括隐藏在文字后的链接。公开 `t.me`、`telegram.me`、`tg://resolve` 聊天/消息链接
在应用内打开；私有 `t.me/c`、`tg://privatepost` 支持已知群组。其他 HTTP(S) 链接由
系统打开。邀请链接会先显示确认预览（见命令页）；广播频道链接仍不支持。
支持 URL、web-view、callback、game 机器人按钮；支付、密码保护、联系人/位置和选择
聊天对象的按钮会提示需要图形客户端。

鼠标是可选入口：单击聊天打开，单击消息或操作项选择，右键消息回复，滚轮滚动指针所在面板。
点击聊天列表或消息区会退出输入模式并保留草稿。
设置与账号行也可点击；对应键盘操作始终可用。

## 设置与账号

`s` 打开自动检查更新、发行通道、Enter 下载行为、底栏中的消息 ID 设置。
`c`、`C` 打开[颜色选择器](Appearance.md)。这些偏好会持久保存，不改写 Lua。
Esc 关闭浮层并恢复先前视图；`?` 显示当前生效的绑定。

`a` 打开账号选择器，用方向键选中账号或添加行，再按 Enter。
F2 轮换已有槽位，F3 添加槽位，最多八个。只有当前账号运行网络工作任务。
会话、消息、媒体、颜色覆盖按账号隔离；切换时重置搜索和会话视图，保留各账号的本地草稿。

## 删除消息

选中已送达消息，按 `d` 或输入 `:delete`。应用从服务器获取最新消息，展示聊天、
消息预览和可用范围。默认选中“取消”；用 Up/Down 或 k/j 选择范围，再按 Enter 提交。
普通聊天按权限提供“仅自己”和“所有人”；超级群采用 Telegram 的全体删除语义；
Saved Messages 仅自己删除。此入口暂不处理服务消息，最终权限由服务器判断。

提交前再次核对消息所属聊天、版本及权限。确认期间消息发生变化会使本次预览失效，
需要关闭后重开。Telegram 没有原子“比较版本再删除”接口，最后核对与请求之间仍可能
发生远端修改。失败保留消息，并将选择恢复为取消。Esc 关闭确认框；已提交的请求继续
执行，结果显示在底栏。删除经有序同步流移除缓存、搜索结果与回复预览，然后才保存
对应同步进度，避免重启后残留已删除内容。

## 复制消息内容

选中已送达消息，按 `y` 或使用 `:copy` / `:copy text` 复制正文或说明文字，不附加作者
和时间。`Y` / `:copy link` 向 Telegram 获取消息链接，并在可用时包含话题/线程。
超级群和频道支持消息链接；私有链接仍需要访问权限。普通私聊和基础群没有可导出的消息链接。

复制时在线检查最新消息和聊天权限；受保护内容、无文字或不可用消息不会改动剪贴板。
请求期间即使切换聊天，仍以开始时的消息为目标。最多同时准备一份内容、写入一次剪贴板。
底栏显示错误，所选消息的操作提示使用 Lua 中实际绑定的复制键。

本机剪贴板在后台写入。Linux 在应用运行期间保留剪贴板所有者；退出后是否还能粘贴取决于
桌面的剪贴板管理器。WSL 必要时使用 Windows PowerShell。SSH 通过 Yazi 的 OSC 52
向所连接的终端请求复制；tmux 也会收到终端复制请求。本机写入失败时同样回退到 OSC 52。
终端协议不提供送达确认，因此“Clipboard request sent”表示已发送请求；终端或 tmux
设置仍可能阻止复制。内容最多 100,000 个 UTF-8 字节，不写入日志或子进程命令参数。

## 转发与 Saved Messages

选中一条已送达消息，按 `f`，或输入 `:forward <chat>`。Tab 复用 `:chat` 的缓存聊天、
ID 和 Lua 别名补全；`saved` 表示当前账号的 Saved Messages。命令缺少参数时按 Enter
不会自动选定目标。选好目标后，预览展示目标名称/ID、账号、来源和最新消息。
Enter 转发，Esc/Ctrl-C 取消；对应可配置 `forward` 上下文中的 `send` / `cancel`。

`g S` / `:save` 打开以 Saved Messages 为目标的同一个预览；`g s` / `:saved` 只打开
收藏聊天，不转发任何内容。目标来自已认证账号身份，不依赖最近聊天中是否存在同名项。
已经缓存的 Saved Messages 聊天可离线打开。

原生转发保留来源署名与媒体，不改动来源和目标聊天的正文草稿。展示预览前和实际提交前
都会检查最新内容保护。服务消息、过期媒体、受保护内容及服务器限制会显示错误。
远端编辑/删除会使已打开预览失效；目标发送权限最终由服务器决定。最后检查与提交之间
仍可能发生远端修改。

失败保留预览和同一个 Telegram 去重 ID，供再次发送。提交前 Esc 丢弃预览；提交后 Esc
关闭视图，请求继续执行。如果后台转发失败，`f` 可继续该预览。预览与重试 ID 当前只在
本次进程中保留；取消后重新选择目标属于新的转发意图。此入口只转发明确选中的一条消息，
不将整组相册或多选消息一起发送。当前目标选择器按聊天选择，不能指定某一个群话题。

新建私聊使用 `:open @username`，打开后按 `i` 输入。`:info` 查看聊天身份和发送限制。
邀请和权限说明见[聊天发现与资料](Chats.md)。
